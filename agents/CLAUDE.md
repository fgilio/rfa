# Agent Artifacts

Use `agents/` as a general artifact area.

## Artifact Types

- General artifacts live directly in `agents/`
- Conversation threads live in `agents/conversations/{thread}/`
- Inactive material can move to `agents/archive/`

## Naming

- General artifacts: `YYYYMMDD-kebab-case.md`
- Conversation files: follow the local instructions inside each thread folder

Do not assume one thread's protocol applies to all of `agents/`.
